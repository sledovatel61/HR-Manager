# tests/ — автоматические тесты

## Структура

- `backend/` — модульные тесты backend (pytest). Запуск: `cd backend && python -m pytest`.
- `e2e/` — зарезервировано под сквозные тесты (появятся вместе с бизнес-функциональностью);

## Правила

- Каждая бизнес-функция покрывается тремя сценариями: happy path, права доступа, ошибочный ввод (см. `agents.md`).
- Тесты не обращаются к внешним сервисам и не требуют запущенного Docker.

## Политика SQLite

Единственное место, где допустим SQLite, — изолированные unit-тесты
(`APP_ENV=test`), без его использования как замены production-БД.
Подробности: [backend/README.md](backend/README.md).
