Никогда не коммитьте private_key в git, не добавляйте в установщик, Docker, логи, диагностический архив.
Сделайте резервную копию в зашифрованном хранилище (VeraCrypt/BitLocker/зашифрованная флешка).
Публичный ключ (base64 44 символа) скопируйте в infra/license/public_key.b64 перед сборкой пилотного образа или в HRM_LICENSE_PUBLIC_KEY.
Автономность: этот HTML работает без интернета. Для secure context (WebCrypto) откройте через run-html.bat (http://localhost:8765) или https. В file:// контексте Edge может блокировать crypto.subtle — тогда используйте run-gui.bat или run-cli.bat из автономного пакета (bundled Python, без интернета, без системного Python).

Справка


Формат канонических байт для подписи (фиксированный порядок, LF, UTF-8):


license_id:<uuid>
client_name:<имя>
issued_at:<YYYY-MM-DDTHH:MM:SSZ>
expires_at:<YYYY-MM-DD>
max_active_users:<число>



Подпись — Ed25519 detached, 128 hex. Проверяется публичным ключом base64 32 байта.


Дата expires_at действует включительно до конца дня 23:59:59 UTC. Например, 2026-12-31 значит валидна до 2026-12-31T23:59:59Z.


Защита от перевода часов: сервер хранит last_seen_at и если текущее время < last_seen_at - 1 час, лицензия блокируется (best-effort).


Инструкция для Марии: Настройки → Лицензия → Загрузить файл .hrmlicense или вставить JSON → Сохранить. При истечении — админ может войти и загрузить новую лицензию, данные не удаляются.


Офлайн: этот HTML работает без интернета. WebCrypto Ed25519 поддерживается в Edge 120+, Chrome 120+, Firefox 120+ (Windows 10/11 Edge по умолчанию — OK). Для file:// контекста crypto.subtle может быть недоступен — используйте run-html.bat (http://localhost) или run-gui.bat (автономный Python, без интернета, без системного Python). Fallback TweetNaCl (nacl-fast.js) используется если WebCrypto недоступен.
