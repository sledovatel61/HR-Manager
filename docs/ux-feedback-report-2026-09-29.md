# Отчёт по UX-замечаниям 29.09.2026 — статус устранения

Дата: 29.09.2026 · Ветка: `arena/01a0edff-hr-manager` (от `main` @ `87e4414`)
Исходные материалы: `docs/UX_FEEDBACK_TASK_2026-09-29.md`,
`prompts/UX_FEEDBACK_AGENT_PROMPT_2026-09-29.md`.

Вердикт готовности релиза 0.14.0: **NO-GO** — устранены все P0-замечания и
два P1-блока, но блоки «Списки документов → мастер» (D) и «Шаблоны →
безопасная загрузка файлов/категории» (E) не реализованы. Релиз остаётся
заблокированным до их закрытия (см. handoff).

## Что устранено (с доказательствами)

### Блок A — Календарь (P0) ✅

1. **Пустой список «Исполнитель».** Лечебный UX: форма событий показывает
   состояние загрузки, ошибку загрузки с повтором и пустое состояние
   «В отделе нет активных пользователей HR» с действием «Обновить список» —
   вместо тихого пустого select (баг `GET /admin/users/hr` не воспроизводим:
   каталог возвращал 3 HR; найден и закрыт класс ошибок «пустой
   обязательный список без действия восстановления»).
2. **Напоминание не редактируется.** Поле теперь переключаемое
   («Без напоминания»/«Напоминание»), значение редактируется, подсказка
   «не позднее начала события», календарь браузера с учётом локали/часового
   пояса, серверная валидация `remind_at < starts_at`. При сдвиге события
   «Напоминание перенесено…» в сайдбаре и форме.

### Блок B — единая связь «событие ↔ напоминание ↔ кандидат» (P0) ✅

1. **Общий домен.** `backend/app/event_reminders.py` + миграция
   `0017_event_reminder_link.py`: `reminders.event_id` (FK, SET NULL,
   индекс) связывает напоминание с событием;
   каскад удаления события уведомляет в UI («Связанное событие удалено»).
2. **Один механизм создания.** Единый `useEventReminderSave` (модалка
   события/напоминания, карточка кандидата) — без дублей и рассинхрона
   статусов. Событие/напоминание: кандидат необязателен.
3. **Кандидат в напоминании.** «Без кандидата» остаётся; серверный поиск
   по ФИО/телефону/email (`GET /candidates/search`), переходы в карточку.
4. `test_event_reminder_link.py` — 14 тестов (схема/права/связи/каскад).

### Блок F — «Мои правила» (P0) ✅

1. Правила и списки грузятся раздельно: сбой списков больше не прячет все
   правила за общей ошибкой страницы.
2. Нет незаполняемого обязательного select: пустое состояние «Нет
   опубликованных списков» с действием «Перейти к спискам» + «Обновить»;
   сохранение блокируется с понятным сообщением.
3. Подсказка при несовпадении этапа (какие списки с какими этапами есть).
4. Серверная проверка публикации/версии/этапа/права покрыта тестом
   (`test_rule_server_revalidates_publication_stage_and_grant`).

### Блок C — Воронка кандидатов (P1) ✅

1. «Kanban» → «Воронка кандидатов» в меню, заголовках, подсказках и
   документации (README, CURRENT_STATUS, ARCHITECTURE).
2. Перенос в любую колонку одним действием (select на карточке,
   keyboard-альтернатива, optimistic + rollback + понятная ошибка);
   тесты переноса в первую/среднюю/последнюю колонки.
3. Автопрокрутка доски у краёв при перетаскивании — длинная воронка не
   требует последовательного ручного скролла.

### Блок G — навигация (P1) ✅

1. Рабочий контур в меню: Кандидаты/Моя очередь, Календарь, Воронка
   кандидатов, График выхода, Напоминания, Уведомления, Аналитика,
   Удалённые + один пункт «Настройки».
2. «Настройки»: Уведомления, Мои правила, Контент и документы (списки +
   шаблоны), Интеграции, Обновления, Лицензия, Администрирование,
   Пользователи — с группировкой и прежними правами доступа.
3. Прямые ссылки сохранены (`#/rules`, `#/documents`,
   `#/admin/diagnostics`, legacy `#/readiness`); хлебные крошки
   «Все настройки → раздел». Серверные проверки ролей не менялись.

## Что НЕ устранено (блокирует релиз)

- **Блок D (P1):** «Списки документов» не переписаны в простой мастер
  (назначение, строки, обязательность, порядок, предпросмотр,
  черновик/публикация); технические ключи/версии не вынесены в расширенные
  сведения.
- **Блок E (P1):** «Шаблоны» — нет ограничений загрузки файлов
  (расширения/размер), категорий (Документ/Чек-лист/Вопросник/Памятка/
  Скрипт), поиска, плейсхолдеров и предпросмотра; материалы `LLM\23.09.2026`
  не инвентаризированы (автоимпорт не выполнялся — как и требовалось).
