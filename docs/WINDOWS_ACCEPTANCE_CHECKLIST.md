# Ручной чек-лист приёмки на Windows (пилот 0.15.0)

Выполняется на **чистой Windows 10/11 x64** (лучше — виртуальная машина) пользователем без прав администратора,
кроме тех шагов, где UAC ожидается явно. Каждый пункт требует отметки и доказательства; без доказательства пункт считается невыполненным.
Автотесты (`infra/windows/tests/run-tests.ps1`) и CI **не заменяют** этот чек-лист: в песочнице нет Windows, Docker и PowerShell.

Артефакты для прогона:
* `HR-Manager-Setup-0.15.0.exe` + его SHA256. Файл берётся из артефакта веточного CI
  `pilot-setup-0.15.0-unsigned` (`SHA256SUMS.txt` лежит рядом с exe) либо из артефакта `pilot-release-0.15.0`
  (workflow `Pilot release`, запускается одной кнопкой, без тега и Release); локально —
  `installer/build.ps1 -Version 0.15.0`. Хэш зафиксированной сборки записан в разделе 4
  `docs/PILOT_FINAL_REPORT.md` и продублирован notice-аннотацией шага «Publish the pilot artifact hashes»
  в джобе `Pilot Setup.exe (unsigned, 0.15.0) + SHA256SUMS`,
* `LicenseIssuer-Portable.exe` + `BUILD-INFO.txt` (SHA256),
* лицензия `pilot.hrmlicense`, выпущенная владельцем.

| # | Шаг | Ожидаемый результат | Отметка | Доказательство |
| --- | --- | --- | --- | --- |

| B2 | Отказаться от установки Docker (снять галочку) → **Установить** | Понятное русское сообщение, что без Docker работа невозможна и что делать; **нет crash-loop**, окно не «мигает», повторный запуск мастера снова предлагает установку | ☐ | скриншот |

| B4 | Отменить UAC (Esc) и повторить установку | Сообщение, что установка Docker отменена и что она продолжится после повторного запуска; ничего не сломано; повторный запуск предлагает установку снова (`docker-pending.json`) | ☐ | скриншот |

### Что считается доказательством

* скриншот окна мастера/трея/браузера;
* сохранённый файл (`update-result.json`, `supervisor.json`, `BUILD-INFO.txt`, отчёт для поддержки);
* вывод команд (`Get-FileHash`, `netstat`, `docker volume ls`, `docker compose ls`, `Get-Process`);
* лог CI-джоба.

### Что проверяется только на Windows (недоступно в текущей среде разработки)

* реальный Docker Desktop (установка, UAC, перезагрузка, движок, WSL2);
* WinForms-трей (значок, меню, окно состояния) и автозапуск после перезагрузки;
* скачивание официального установщика Docker и установка Python/issuer-сборки;
* реальный Inno Setup-инсталлятор и его экраны;
* поведение SmartScreen при отсутствии сертификата подписи.
