# HR Manager — инструкция для Марии (пилот, 2 страницы)

Это простая инструкция. Ничего программировать не нужно — только клики мышью.

---

## 0. Что подготовить заранее — Docker Desktop

HR Manager работает в контейнерах. Один раз поставьте Docker Desktop:

1. Откройте сайт **docker.com** → скачайте **Docker Desktop для Windows**.
2. Запустите установщик → оставьте галочку **WSL2** → **Install** → **Restart** (перезагрузка).
3. После перезагрузки запустите **Docker Desktop** → примите лицензионное соглашение → дождитесь, когда внизу появится **Engine running** (может занять минуту, появится иконка-кит в трее).
4. Проверьте виртуализацию: `Диспетчер задач → Производительность → ЦП` — должно быть **Виртуализация: Включено**. Если «Отключено» — перезагрузите ПК → войдите в BIOS (обычно F2/Del при включении) → включите **VT-x / AMD-V / Virtualization**.

Готово — Docker можно закрыть (он сам запустится при следующем включении).

## 1. Установка HR Manager

1. Вам прислали файл `HR-Manager-Setup-0.14.0.exe` (цифры — версия). Сохраните на рабочий стол.
2. Дважды кликните. Windows покажет синее окно **SmartScreen** «Система защитила компьютер» → нажмите **Подробнее** → **Выполнить в любом случае**. Это нормально для пилота: покупного сертификата пока нет, файл безопасен.
3. Мастер спросит:
   * **Роль** — выберите `HR` (можно поменять позже),
   * **Фамилия** — введите свою фамилию,
   * **Часовой пояс** — оставьте `Europe/Moscow`.
   Нажмите **Установить**.
4. Появится чёрное окно с бегущими строками (сборка, это 2–5 минут) — не закрывайте. В конце откроется браузер на `http://127.0.0.1:8080`.
5. Задайте **пароль администратора** (не менее 12 символов, запишите!), рабочие дни и тихие часы → **Создать**. Вы вошли как администратор.

Ярлыки появились:
* На рабочем столе и в меню «Пуск» — **HR Manager** (открывает программу),
* Только в меню «Пуск» — **HR Manager — отчёт для разработчика**, **перезапуск**, **доступ по сети**.

После перезагрузки ПК программа поднимется сама (если запущен Docker Desktop) или кликните ярлык **HR Manager**.

---

## 2. Загрузка лицензии

Без лицензии работать нельзя (увидите баннер). Вам прислали файл `*.hrmlicense`:

1. Войдите в **HR Manager** → раздел **Лицензия** (в рабочем пространстве).
2. Нажмите **Загрузить лицензию** → выберите присланный файл → **Загрузить**.
3. Увидите: имя клиента, срок действия, лимит пользователей, сколько дней осталось.

Лицензия сохраняется, переживает перезагрузки и обновления.

---

## 3. Доступ для коллеги по сети (необязательно)

Второй HR работает со своего ПК через браузер, ничего не устанавливая:

1. Убедитесь, что оба ПК в одной сети (один Wi-Fi/офисная сеть, профиль сети — **Частная**).
2. На вашем ПК откройте меню «Пуск» → **HR Manager — доступ по сети** → нажмите **Включить**. При первом включении Windows попросит разрешение для Firewall — нажмите **Да** (один раз).
3. Ярлык покажет адрес, например `http://MARIYA-PC:8080` и `http://192.168.1.20:8080` — скопируйте и дайте коллеге.
4. Коллега открывает этот адрес у себя в браузере → логинится. Создайте для него пользователя в разделе **Пользователи** (лимит из лицензии включает и вас).
5. Чтобы выключить доступ — тот же ярлык → **Выключить** (порт снова только на вашем ПК).

> Доступ по сети — без шифрования (HTTP). В офисной сети это принято для пилота. Страницы первого запуска `/setup/*` всё равно открываются только с вашего ПК.

---

## 4. Отправка отчёта разработчику

Если что-то пошло не так, разработчику нужен отчёт:

1. Меню «Пуск» → **HR Manager — отчёт для разработчика** (или рабочий стол).
2. На рабочем столе появится файл `HR-Manager-report-2026-09-29_12-30-00.zip`.
3. Отправьте этот файл владельцу/разработчику (email/мессенджер).

Внутри только техническая информация (диагностика, логи, версия, срок лицензии) — **без паролей, токенов, ключей и без данных кандидатов** (ФИО/телефоны/email не попадают).

Подсказка также видна в разделе **Готовность пилота** в приложении.

---

## 5. Установка обновления

Владелец прислал новый `HR-Manager-Setup-0.15.0.exe`:

1. Закройте HR Manager (можно не закрывать — установщик сам остановит).
2. Запустите новый `Setup.exe` **поверх старого** (дважды клик, снова SmartScreen → Подробнее → Выполнить). Данные, пароли и лицензия **сохранятся** — установщик сначала делает шифрованный бэкап, потом меняет файлы, делает миграции и проверяет. При ошибке — автоматический откат к прежней версии.
3. Дождитесь конца установки и откройте **HR Manager** — проверьте, что ваши кандидаты на месте.

---

## 6. Что делать, если не открывается

1. Проверьте, что запущен **Docker Desktop** (иконка-кит в трее, Engine running). Если нет — запустите и подождите минуту.
2. Кликните ярлык **HR Manager** на рабочем столе.
3. Если всё ещё не открывается — меню «Пуск» → **HR Manager — перезапуск** (перезапускает контейнеры, данные сохраняются) → подождите 30 секунд → снова ярлык **HR Manager**.
4. Если не помогло — создайте **отчёт для разработчика** (п.4) и отправьте владельцу.

**Не удаляйте** программу через «Установку и удаление», если хотите сохранить данные. Просто перезапустите. Удаление сохраняет данные, но лучше не трогать.
