# HR Manager — инструкция для Перепечай (пилот 0.15.0, 2 страницы)

Это простая инструкция. Программировать ничего не нужно — только клики мышью.
Если что-то пошло не так — в конце есть раздел «Если не открывается», а рядом всегда есть значок HR Manager у часов.

---

## 0. Что нужно знать заранее (1 минута)

1. **Два отдельных компонента.** Вам нужен `HR-Manager-Setup-0.15.0.exe` и отдельно установленный Docker Desktop. Если Docker Desktop уже установлен, дополнительная загрузка не нужна.
2. **Docker Desktop устанавливается вручную.** Если его нет, откройте только официальный сайт [docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop/), скачайте Docker Desktop и запустите установку сами. Прочитайте и примите лицензию самостоятельно. Windows может запросить UAC или перезагрузку; после перезагрузки завершите именно ручную установку Docker и запустите Docker Desktop. HR Manager не принимает лицензию, не устанавливает Docker автоматически и не продолжает его установку через `resume`.
3. **Необязательный файл рядом с Setup.exe.** Иногда владелец может прислать отдельный `DockerDesktopInstaller.exe`. HR Manager может скопировать его в папку приложения, но никогда не запускает автоматически. Использовать его или скачать установщик с официального сайта — решаете вы; источник и SHA256 должны быть указаны в манифесте/суммах дистрибутива.
4. **Сначала дождитесь Engine.** Перед первым запуском HR Manager запустите Docker Desktop из меню «Пуск» и дождитесь состояния **«Engine running»**.
5. **SmartScreen и UAC.** Для Setup.exe может появиться SmartScreen (в пилоте файл может быть неподписан). Сам Setup работает без запроса прав администратора; UAC может появиться, когда вы вручную запускаете Docker installer.
6. *Про лицензию Docker Desktop честно:* для небольших организаций он бесплатный; если ваша организация крупная (больше 250 сотрудников или выручка больше 10 млн $ в год), владельцу нужно оформить подписку Docker. Приложение этого не скрывает и ничего не обходит.
7. **Defender и брандмауэр не трогаем.** Никакие команды PowerShell запускать не нужно, защиту Windows отключать не нужно.

---

## 1. Установка HR Manager (5–10 минут после настройки Docker)

1. Убедитесь, что Docker Desktop запущен и показывает **«Engine running»**. Если он ещё не установлен, сначала выполните ручную установку из раздела 0.
2. Сохраните присланный `HR-Manager-Setup-0.15.0.exe` на рабочий стол.
3. Дважды кликните по нему. Windows может показать SmartScreen «Система защитила компьютер» → **Подробнее** → **Выполнить в любом случае**. Это нормально для пилота: покупного сертификата подписи пока нет, файл проверен и прислан владельцем.
4. Мастер установки спросит:
   * **Роль** — выберите `HR` (можно поменять позже),
   * **Фамилия** — введите свою фамилию,
   * **Часовой пояс** — оставьте `Europe/Moscow`.
   Кнопки или галочки для установки Docker нет. Нажмите **Установить**.
5. Мастер копирует файлы и запускает HR Manager. Если Docker Desktop отсутствует или Engine не готов, на странице Finish появится честное сообщение **«Файлы установлены, но HR Manager не готов»**. Это не успешный запуск приложения: Setup возвращает код `10`, а приложение не объявляется готовым. Установите/запустите Docker Desktop вручную с официального сайта, дождитесь **«Engine running»** и затем нажмите ярлык **HR Manager** или повторите запуск приложения. `resume` не нужен для Docker.
6. Если всё готово, браузер откроется сам на странице `http://127.0.0.1:8080`, и мастер сообщит, что установка завершена. Если браузер не открылся — нажмите ярлык **HR Manager** на рабочем столе.
7. Задайте **пароль администратора** (не меньше 12 символов, запишите его!), рабочие дни и тихие часы → **Создать**. Вы вошли как администратор.

Ярлыки после установки:
* **Рабочий стол и меню «Пуск»** — **HR Manager** (открывает программу),
* **Меню «Пуск»** — **HR Manager — доступ по сети**, **HR Manager — отчёт для разработчика**,
* **У часов** (рядом с временем) — значок **HR Manager**: это «пульт управления» (см. раздел 2).

После перезагрузки компьютера программа поднимается сама.

## 2. Значок HR Manager у часов (трей)

Нажмите на значок правой кнопкой — появится меню:

| Пункт | Что делает |
| --- | --- |
| **Открыть HR Manager** | Открывает программу в браузере (сначала проверяет, всё ли запущено). |
| **Проверить состояние** | Показывает окно простыми словами: что работает, что нет, и кнопки **Повторить**, **Открыть приложение**, **Создать отчёт для поддержки**. |
| **Перезапустить приложение** | Аккуратно перезапускает программу. Данные и лицензия сохраняются. |
| **Создать отчёт для поддержки** | Готовит файл `HR-Manager-report-...zip` на рабочем столе для разработчика. |
| **Остановить приложение** | Останавливает программу (на время). **Данные, база и лицензия остаются на месте.** |
| **Выйти** | Закрывает значок у часов. Программа в браузере тоже перестанет открываться, пока вы снова не запустите HR Manager. Данные не удаляются. |

Важно:
* **Закрытие браузера ничего не останавливает** — программа продолжает работать, вы просто закрыли окно.
* Пункты меню ненадолго становятся серыми, пока выполняется предыдущее действие — это защита от двойных нажатий.
* Повторный запуск значка не создаёт второй значок и второй «супервизор» — он всегда один.

## 3. Лицензия

Без лицензии работать нельзя (увидите баннер в программе). Владелец присылает файл `*.hrmlicense`:

1. В HR Manager откройте раздел **Лицензия**.
2. Нажмите **Загрузить лицензию** → выберите присланный файл → **Загрузить**.
3. Должно появиться **«Лицензия активирована»** и показано: имя клиента, срок действия, лимит пользователей, сколько дней осталось.

Если что-то не так — программа объяснит по-русски, без технических терминов:
* «Файл повреждён или это не файл лицензии — попросите владельца прислать лицензию заново»;
* «Срок действия лицензии закончился — попросите владельца продлить»;
* «Это файл вашего секретного ключа. Его нельзя загружать в программу и никому не отправляйте. Пришлите владельцу сообщение об ошибке»;
* «Подпись лицензии не совпадает с ключом этой установки — пришлите владельцу ошибку целиком».

Лицензия сохраняется при перезапусках и обновлениях.

## 4. Доступ для коллеги по сети (необязательно)

Второй HR работает со своего компьютера через браузер, ничего не устанавливая:

1. Убедитесь, что оба компьютера в одной сети и профиль сети **Частная**.
2. Меню «Пуск» → **HR Manager — доступ по сети** → **Включить**. Windows один раз спросит разрешение брандмауэра — нажмите **Да**.
3. Ярлык покажет адрес вида `http://MARIYA-PC:8080` и `http://192.168.1.20:8080` — отправьте его коллеге.
4. Создайте коллеге пользователя в разделе **Пользователи** (лимит из лицензии включает и вас).
5. Чтобы выключить — тот же ярлык → **Выключить** (программа снова доступна только на вашем компьютере).

> По умолчанию HR Manager доступен **только на вашем компьютере**. Доступ по сети включается явно, по вашей команде.
> В офисной сети это HTTP (без шифрования) — для пилота это принято.

## 5. Отчёт для поддержки

Если что-то не работает: значок у часов → **Создать отчёт для поддержки** (или меню «Пуск» → **HR Manager — отчёт для разработчика**).
На рабочем столе появится файл `HR-Manager-report-...zip` и сообщение **«Отчёт создан на рабочем столе»** — отправьте его владельцу.

Внутри только техническая информация: версия, состояние служб, журналы работы.
Пароли, ключи и токены вырезаются автоматически; адреса почты и телефоны — тоже.
Но автоматика не идеальна: **имена и другой текст из журналов могут в архиве остаться**.
Поэтому перед отправкой **откройте архив и просмотрите его** (в первую очередь файлы `logs-*.txt`),
а отправляйте только владельцу и по закрытому каналу — не в общий чат и не на публичную почту.
Внутри архива для этого лежит файл `README-ПЕРЕД-ОТПРАВКОЙ.txt` с тем же предупреждением.

## 6. Обновление на новую версию

Владелец присылает новый `HR-Manager-Setup-0.15.1.exe` (или другую версию):

1. Дважды кликните по новому файлу (можно поверх старой версии — так и нужно).
2. Мастер покажет: **что за версия сейчас**, **какая станет**, **что нового** и предупреждение, что **данные сохранятся**
   («Перед обновлением автоматически создаётся резервная копия. Пользователи, настройки, вложения и лицензия сохраняются.»).
3. Нажмите **Обновить** и не закрывайте окно. Мастер сам: проверит состояние, сделает резервную копию, заменит файлы, выполнит миграции и проверит запуск.
4. В конце: **«Обновление завершено»** и новая версия открывается в браузере.
5. Если что-то пойдёт не так, мастер сам вернёт прежнюю версию и напишет: **«Обновление не удалось, восстановлена прежняя версия»** — данные и лицензия при этом сохраняются. Создайте отчёт для поддержки (раздел 5) и отправьте владельцу.

Подробно (включая проверку SHA256 и порядок отката) — в `docs/UPDATE_GUIDE.md`.

## 7. Если не открывается

1. Посмотрите на значок у часов: **HR Manager → Проверить состояние**. В окне будет написано, что именно не работает, и будут кнопки **Повторить** и **Открыть приложение**.
2. Если сообщение говорит, что не найден Docker Desktop или не готов Docker Engine, установите Docker Desktop только вручную с официального сайта из раздела 0 либо запустите уже установленный Docker Desktop. Дождитесь **«Engine running»**, затем нажмите **Повторить** или снова откройте HR Manager.
3. Если не помогло — значок у часов → **Перезапустить приложение**, подождите 30 секунд, нажмите **Открыть HR Manager**.
4. Если совсем не открывается — **Создать отчёт для поддержки** (раздел 5) и отправьте файл владельцу.
5. Если перезагрузка понадобилась для ручной установки Docker, перезагрузите компьютер, запустите Docker Desktop и дождитесь Engine. HR Manager не возобновляет Docker-установку: не нужно запускать `resume` для Docker. После готовности Engine откройте приложение ярлыком HR Manager.

**Чего делать не нужно:** удалять программу через «Установку и удаление программ», отключать Defender или брандмауэр, запускать команды PowerShell, что-то искать в папках и что-либо удалять вручную.
Удаление программы (если владелец попросит) не удаляет данные, но лучше сначала спросить владельца.
