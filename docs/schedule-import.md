# Импорт и синхронизация графика выхода

Реализация использует существующие `ScheduleImport` и `ScheduleImportRow`;
отдельной параллельной системы импорта нет. Миграция синхронизации — `0021`,
она зависит от `0020` (вложения, PR #48) и должна оставаться после неё в линейной
цепочке миграций. Следующая за ней — `0022` (нормализованная должность, PR #49);
при добавлении новых ревизий нумеровать продолжать с `0023`.

## Повторная загрузка и текущие строки

Подтверждённый файл становится текущим снимком исходной таблицы. При повторной
загрузке строки устойчиво сопоставляются, изменённые поля и дата/время
синхронизируются, новые строки добавляются, а исчезнувшие становятся
неактивными без физического удаления. Исторические версии остаются в
`ScheduleImportRow`. Актуальный XLSX формируется из последнего снимка и живых
полей кандидатов/служебных записей; в нём сохраняются порядок и исходные
колонки, а технические поля БД не экспортируются.

Импортёр сохраняется как автор импорта. Сам факт импорта не назначает его
ответственным HR. Руководитель или HR с действующим доступом ко всем кандидатам
может назначать и снимать ответственного для одной или нескольких строк; каждое
реальное изменение назначения аудируется. Строки людей без даты/времени или
без назначенного HR остаются в текущем наборе и Excel-экспорте.

## Аналитика неназначенных кандидатов

**Импортированные неназначенные кандидаты попадают в аналитику только после
ручного назначения ответственного HR.** Пока `owner_user_id IS NULL`, ledger-факты
для кандидата не записываются. Само назначение не создаёт задним числом факт
`candidate_created`; после назначения учитываются поддерживаемые аналитические
события, если они происходят. Панель текущего импорта показывает подсказку,
когда в снимке есть неназначенные люди.

Миграция `0021` заполняет для прежних строк известные поля из кандидатов и
служебных записей. Содержимое старого исходного Excel не хранилось, поэтому
`source_values` для таких снимков заполняется пустым JSON-массивом; при первой
повторной загрузке этот неизвестный массив сам по себе не считается изменением.
