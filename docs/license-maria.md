# Лицензия — инструкция для Марии (администратор, без терминала/GitHub/Docker)

Вам выдали файл лицензии `*.hrmlicense` от владельца. Это офлайн-файл с подписью, без интернета. Он разрешает работу HR Manager на вашем ПК до указанной даты и с указанным лимитом пользователей.

## Что такое лицензия

- Для **инсталляции/сервера**, не per-HR ключ. Вы — первый администратор, лимит включает вас.
- Содержит: имя пилота, действует до (дата включительно до конца дня по UTC), лимит активных пользователей, подпись.
- Проверка — серверная, не только скрытие кнопок.

## Как загрузить лицензию (первый раз)

1. Войдите в HR Manager как администратор (логин/пароль, которые вы задали при первом запуске).
2. Откройте раздел **Лицензия** в меню (иконка щит) — или перейдите по `#/license`.
3. Вы увидите статус: «Лицензия не установлена» — это нормально для первого запуска.
4. Нажмите **Выберите файл** → выберите файл `*.hrmlicense`, который вам прислал владелец.
   - Или вставьте JSON лицензии в поле «Или вставьте JSON» (если вам прислали текст).
5. Нажмите **Загрузить лицензию**.
6. Увидите: клиент, действует до, лимит, активных пользователей, дней осталось.
7. Готово — можете работать.

> Никакого терминала, GitHub, Docker, сертификатов не нужно. Только браузер и файл.

## Как понять, что лицензия скоро истекает

На экране Лицензия показывается «Дней осталось». Если осталось мало — попросите владельца выпустить новую заранее.

## Что делать при истечении

- При истечении срока обычная работа останавливается: вы увидите сообщение «Срок лицензии истёк ... Администратор может войти и загрузить новую лицензию».
- **Данные не удаляются** — кандидаты, календарь, аналитика сохраняются.
- Вы (администратор) всё ещё можете войти в систему.
- Откройте **Лицензия** → загрузите новый файл, который вам пришлёт владелец.
- После загрузки — работа продолжается без переустановки и без потери данных.
- Диагностика, бэкапы, статус остаются доступны даже при истечении.

## Лимит пользователей

- Лимит включает вас. Например, лимит 5 = вы + 4 HR/руководителя.
- Если попытаетесь создать 6-го активного пользователя — сервер отклонит с сообщением «сейчас активных X, а новый лимит Y».
- Чтобы добавить пользователя при достижении лимита — сначала отключите лишнего (деактивируйте), затем создайте нового, или попросите владельца выпустить лицензию с большим лимитом.

## Частые ошибки (русские сообщения)

- «Лицензия не установлена. Загрузите файл лицензии...» — загрузите файл в разделе Лицензия.
- «Подпись лицензии недействительна. Убедитесь, что файл выдан владельцем и не изменён.» — файл повреждён или изменён, попросите владельца прислать заново, не редактируйте файл вручную.
- «Срок лицензии истёк 2026-12-31 (действовала до конца дня по UTC). Администратор может войти и загрузить новую лицензию.» — срок истёк, загрузите новую.
- «Невозможно применить лицензию: сейчас активных пользователей X, а новый лимит Y...» — уменьшите число активных пользователей или попросите лимит больше.
- «Обнаружен перевод системного времени назад...» — проверьте часы на ПК, установите правильное время.
- «LICENSE_PUBLIC_KEY не настроен на сервере...» — обратитесь к владельцу, публичный ключ не установлен в пилотном образе.

## Безопасность

- Файл лицензии — не секретный, но содержит имя клиента и подпись. Не публикуйте его в интернете.
- Приватный ключ — только у владельца, вам его не дают и не нужен.
- В логах и диагностике никогда не показываются полные ключи/подписи — только отпечаток.

## Куда обращаться

- Если не получается загрузить лицензию — напишите владельцу, приложите скриншот ошибки (без редактирования файла).
- Если HR Manager не открывается — проверьте, что Docker Desktop запущен и порт 8080 свободен, затем `hr-manager.ps1 -Action diagnostics`.
