## Правила подготовки к импорту

1. Сначала составить карту: источник → тип контента → должность/этап → владелец
   → статус проверки.
2. Извлекать методические идеи и структуру, а не переносить непроверенный текст
   в production автоматически.
3. Удалять или заменять персональные данные, примеры с реальными кандидатами и
   неподтверждённые контакты.
4. Для каждого опубликованного материала хранить автора, версию, дату проверки,
   область применения и предупреждения об ограничениях.
5. Для юридических и финансовых положений фиксировать ревьюера и дату ревью.
6. Запускать контент через draft → review → published; пользователи видят только
   опубликованную версию.
7. Связывать заполненное интервью или сгенерированный документ с точным
   snapshot версии, которая использовалась.
