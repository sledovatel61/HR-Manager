# HR Manager

Сетевая система для командного подбора персонала.

## Цель

Несколько HR-менеджеров работают с единой базой кандидатов через браузер. Каждый видит свою рабочую очередь, но при необходимости может найти и принять кандидата коллеги. Руководитель видит общую картину, историю действий и показатели каждого сотрудника.

## Статус

Проект начинается заново на уровне архитектуры. Предыдущий PyQt6/SQLite-прототип сохранён вне этого репозитория как источник бизнес-идей и не является кодовой базой нового продукта.

## Принципиальные решения

- web-first интерфейс с адаптивным современным UI;
- серверная PostgreSQL как единый источник данных;
- API с серверной авторизацией и разграничением доступа;
- аудит всех критичных действий;
- ежедневные автоматические резервные копии и проверка восстановления;
- формы, шаблоны и отчёты как версионируемый контент, а не зашитые навсегда в код;
- desktop-оболочка возможна позже, но не является обязательной.

## Безопасность

В production нельзя использовать общую ссылку на SQLite-файл или хранить пароли в открытом виде. Production-развёртывание должно использовать HTTPS, PostgreSQL, хеширование паролей, роли, аудит, ограничение сессий и проверенные backup/restore-процедуры.
