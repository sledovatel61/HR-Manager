На ПК два стека:

| 8080 | **рабочее приложение** | `hr-manager` | `hr-manager_pgdata` |
| 8081 | **стек приёмки** | `hr-manager-pilot` | `hr-manager-pilot_pilot_pgdata` |

Все резервные копии, удаления и восстановления томов шли с `hr-manager-pilot`,
то есть со стеком приёмки. Рабочий стол на 8080 не останавливался и не трогался.

**Приёмку можно спокойно гонять на 8081 — это и есть стек для неё.** Логиниться
на 8081 учётной записью от 8080 нельзя: разные базы.

## Что найдено и починено локально

`Common.psm1`, функция `Invoke-HrmOpenBrowser`:

```powershell
$open = (Test-HrmInteractive -or $global:HrmOpenBrowser -or $env:HRM_OPEN_BROWSER -eq "1")
```

PowerShell разбирает это как вызов команды с аргументами, а не как логическое
выражение. В неинтерактивном режиме результат всегда `False`, каким бы ни был
флаг. Продемонстрировано: с истинным флагом — `False`; вызов функции в скобках —
`True`.

**Почему это важно:** без автоматического открытия браузера пользователь не видит
экран регистрации, то есть приложение «оставляет неработоспособным» — ровно та
исходная жалоба, с которой начиналась задача.

Починка — заключить вызов функции в скобки. Добавлен регрессионный тест,
355 тестов проходят на Windows PowerShell 5.1, `git diff --check` чистый.

### 6. Лицензия

Поток лицензирования автономный: владелец выдаёт подписанный файл `.hrmlicense`,
администратор загружает его через `#/license`. Публичный ключ проверки — это НЕ
лицензия. Отсутствие лицензии до загрузки — ожидаемое состояние, а не сбой
приёмки.

Если нужна полная приёмка с рабочими разделами — нужен выданный владельцем
`.hrmlicense`. Это отдельный шаг, не блокирующий мерж починки.
