## Что я установил по коду — это менять нельзя без причины

1. **Кириллица сервером поддерживается.** В бэкенде есть `transliterate_surname`
   (`setup_owner.py:103`) и `build_owner_username` (`:126`) — из фамилии строится
   логин `owner.<транслит>`. То есть `«Перепечай»` схема принимает: `surname` —
   `Field(min_length=1, max_length=60)`, девять символов проходят с запасом.

2. **Значит фамилия — не отдельный дефект.** Она следствие: регистрация не
   состоялась, потому что claim не выдал тикет. Чинить «фамилию» отдельно не надо.

3. **422 — это отказ валидации тела запроса**, и FastAPI возвращает в ответе
   массив `detail` с именем поля. Схема (`schemas.py:1516-1524`) проверяет ровно
   четыре поля:

   | Поле | Требование | Что шлёт движок |
   |---|---|---|
   | `exchange_token` | 43…256 символов | `New-HrmHex 32` → **64** hex-символа |
   | `surname` | 1…60 | `«Перепечай»` (9) |
   | `working_mode` | `hr`/`manager`/`admin` | `hr` |
   | `timezone` | до 64 или null | `Europe/Moscow` |

   По типам всё сходится. Значит либо токен в `secrets.json` короче 43, либо тело
   уходит не тем, чем кажется. **Тело ответа 422 называет поле — это и есть ответ.**

4. **`supervisor.json.tmp`** пишется `Set-HrmJsonFile` (`Common.psm1:625-635`):
   `Set-Content … .tmp` → `Move-Item -Force` → `Protect-HrmFile`. Падение на
   записи `.tmp` само по себе не объясняется кодом, нужен текст исключения из
   журнала, а не пересказ.

## Задача 1 — достать причину 422 (главная)

Пилот **поднят и healthy**, токен на диске. Повторить claim вручную, без установки:

```powershell
$state = "$env:LOCALAPPDATA\HRManager"
$secrets = Get-Content "$state\secrets.json" -Raw | ConvertFrom-Json
$tok = [string]$secrets.HRM_EXCHANGE_TOKEN

"ДЛИНА ТОКЕНА: $($tok.Length)"     # нужно >= 43; если меньше — причина найдена
"есть ли тикет:  $([bool]$tok)"

# порт бэкенда пилота — из pilot.env, не угадывать
$envPort = (Get-Content "$state\pilot.env" -Raw |
            Select-String 'HRM_PILOT_TRUST_PORT=(\d+)').Matches.Groups[1].Value
$uri = "http://127.0.0.1:$envPort/api/setup/owner/claim"
"адрес: $uri"

$body = @{
    exchange_token = $tok
    surname        = 'Перепечай'
    working_mode   = 'hr'
    timezone       = 'Europe/Moscow'
} | ConvertTo-Json -Compress

try {
    $r = Invoke-WebRequest -Uri $uri -Method POST -Body $body `
           -ContentType 'application/json' -UseBasicParsing `
           -Headers @{ 'X-Real-IP' = '127.0.0.1' }
    "СТАТУС: $($r.StatusCode)"
} catch {
    "СТАТУС: $([int]$_.Exception.Response.StatusCode)"
    "ТЕЛО ОТВЕТА: $($_.ErrorDetails.Message)"    # ← ЭТО и есть причина
}
```

Прислать строки `ДЛИНА ТОКЕНА`, `СТАТУС`, `ТЕЛО ОТВЕТА`. Токен в отчёт **не
включать** — только его длину.

Если тикет уже создан и токен израсходован — будет 409, это нормально и не наша
ошибка; тогда чистим только тикет и повторяем. Если 422 — тело ответа назовёт поле.
