## Осталось сделать

### 1. Живой отказ сетевому клиенту (обязательно)

Перезапустить тестовый стек на `0.0.0.0` и обратиться к нему **по сетевому IP
этого же ПК**, а не по `127.0.0.1`, с подделанным `X-Real-IP: 127.0.0.1`.

```powershell
# в test.env выставить HRM_PILOT_BIND=0.0.0.0, затем
docker compose -p hrm-firstrun-test -f infra\docker-compose.yml -f infra\compose.pilot.yml --env-file $env:TEMP\firstrun-test.env up -d

$ip = (Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -like "192.168.*" -or $_.IPAddress -like "10.*" } | Select-Object -First 1).IPAddress
$body = @{ exchange_token = "<СВЕЖИЙ токен>"; surname = "Сеть"; working_mode = "<режим>"; timezone = "Europe/Moscow" } | ConvertTo-Json
try {
    Invoke-RestMethod -Uri "http://${ip}:28091/setup/owner/claim" -Method Post -Body $body -ContentType "application/json" -Headers @{ "X-Real-IP" = "127.0.0.1" }
    "ОПАСНО: сетевой клиент прошёл"
} catch {
    "ОТКАЗАТО (ожидаемо): $($_.Exception.Response.StatusCode.value__)"
}
```

Токен свежий: предыдущий после успешного claim погашен.

**Ожидание: отказ.** Публичный слушатель nginx перезаписывает `X-Real-IP` на
`$remote_addr` — сетевой адрес, не loopback. Доверенный порт 28002 и порт claim
28001 при этом обязаны остаться на `127.0.0.1`.

Обращение с этого же ПКа по сетевому IP — доказательство сетевого пути, но не
доказательство с отдельного устройства. Если есть вторая машина, проверить и с
неё.

## Замечания к интерфейсу — не блокируют мерж

1. Фамилия на экране первого запуска показана без редактирования: она приходит из
   установщика, а в программе задаются пароль и настройки. Проверено по коду —
   `FirstRunSetup.tsx` намеренно рендерит её как текст. Если фамилию нужно
   выбирать в программе, текущая форма этого не поддерживает.
2. На свежей базе без лицензии рабочие разделы отвечают **403 `no_license`**, а
   интерфейс показывает «Недостаточно прав» и «Backend недоступен». Причина не в
   правах и не в сервере: лицензия ставится отдельно, админом, через
   `POST /license/upload` (есть также `GET /license/status` и
   `POST /license/upload-json`). API честно отдаёт `X-License-Status: no_license`
   и код `no_license` — фронтенд это не использует.

   **Практическое следствие для пилота:** после установки и регистрации нужно
   загрузить лицензию, иначе приложение выглядит сломанным. Живой пилот от 10.09
   лицензию уже имеет, поэтому там это не проявлялось.
