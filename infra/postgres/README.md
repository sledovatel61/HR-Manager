# infra/postgres

PostgreSQL 16 поднимается контейнером `db` из корневого `docker-compose.yml`:

- том `pgdata` смонтирован в `/var/lib/postgresql/data` — данные переживают
  пересоздание контейнера (`docker compose down`; полный сброс — `down -v`);
- healthcheck — `pg_isready`, backend стартует только после готовности БД;
- порт публикуется на `127.0.0.1` для локальной разработки и `psql`;
  для доступа из сети задайте `DB_BIND=0.0.0.0` в `.env`.

Доступ к консоли БД: `docker compose exec db psql -U hr_manager -d hr_manager`.

## Следующие этапы

- пользователь БД с минимальными правами для приложения (отдельно от суперюзера);
- параметры производительности и логирования;
- ежедневные шифрованные backup + проверка восстановления (Этап 7).
