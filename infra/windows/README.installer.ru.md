# HR Manager — инструкция для пользователя

Эта короткая инструкция описывает установку и повседневную работу с **HR Manager**
на вашем компьютере. Для работы не нужны технические знания: не нужно открывать
терминал, редактировать файлы или настраивать базы данных.

## Что делает программа

Ваш компьютер становится **локальным сервером HR Manager**. Приложение открывается
в обычном браузере и доступно **только на этом компьютере** по адресу
`http://127.0.0.1:8080`. Все данные хранятся на этом компьютере.

## Установка

1. Запустите `HR Manager Setup.exe`.
2. Выберите основную рабочую роль: **HR**, **Руководитель** или **Администратор**.
   Это только стартовый экран — как владелец установки вы получаете полный доступ
   независимо от выбранной роли.
3. Введите свою фамилию (только буквы, дефис или пробел).
4. Нажмите **«Установить»** и дождитесь завершения.

Если на компьютере ещё нет Docker Desktop, мастер сам предложит установить его из
официального источника. После этого может потребоваться перезагрузка компьютера —
установка продолжится с того же шага автоматически, форму заполнять заново не нужно.

## Первый запуск

После установки откроется окно приложения. Введите и подтвердите **пароль** (не
менее 12 символов), затем при желании выберите часовой пояс и тихие часы. Email и
Telegram необязательны — их можно пропустить и настроить позже.

## Значки на рабочем столе

* **HR Manager** — открывает приложение.
* **Диагностика HR Manager** — показывает состояние установки; этот отчёт можно
  переслать в поддержку (он не содержит паролей и личных данных).

## Остановка, запуск и обновление

* Приложение запускается автоматически после установки. Чтобы запустить его позже,
  откройте ярлык **HR Manager**.
* Обновление выполняется запуском нового `HR Manager Setup.exe` поверх установки.
  Перед обновлением программа автоматически создаёт зашифрованную резервную копию.

## Удаление

Удаление выполняется через **Параметры → Приложения → Удалить HR Manager**.
База данных и резервные копии **сохраняются** по умолчанию. Полное удаление данных —
отдельное действие с подтверждением.
