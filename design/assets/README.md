# assets/

Каталог зарезервирован для статических иллюстративных материалов дизайн-этапа
(например, экспортированных скриншотов интерактивного прототипа для обзора
владельцем продукта без запуска Vite-сервера).

В рамках этой итерации скриншоты не приложены: интерактивный прототип
запускается локально (см. `../../design-prototype/README.md`) и полностью
покрывает все обязательные экраны — это надёжнее статичных картинок для
демонстрации фактического поведения (фокус, клавиатурная навигация,
переходы между состояниями).

Если потребуется приложить статические превью для быстрого обзора без
запуска сервера, разместите их здесь как `<screen-name>.png` с коротким
подписанным именем на английском (например, `candidates-table.png`,
`candidate-drawer.png`).
