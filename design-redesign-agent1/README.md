# HR Manager — Mission Control

Интерактивный статический концепт редизайна, выбранное направление — **№3 Mission Control**. Это самостоятельный preview: боевой frontend и его зависимости не изменялись.

## Запуск

Из корня репозитория:

```bash
cd design-redesign-agent1
python3 -m http.server 4173 --bind 0.0.0.0
```

Откройте `http://localhost:4173` локально или используйте live-preview этой сессии. Сборка и установка пакетов не нужны.

## Что попробовать

- Навигация по hash-ссылкам: «Моя очередь», «Кандидаты», «Воронка», «Аналитика», «Новый список».
- `Ctrl/Cmd + K` — command palette; `/` на странице кандидатов фокусирует поиск.
- В профиле кандидата переключаются вкладки; фильтры ищут по имени и этапу.
- Воронка поддерживает drag-and-drop, а также `Alt + ←/→` для перемещения сфокусированной карточки.
- На верхней панели переключаются светлая/тёмная тема, плотность и системные шрифты.
- На странице документов работает двухшаговый мастер с live-preview.

## Файлы

- `index.html` — экраны и доступная семантическая разметка.
- `style.css` — Mission Control UI и светлая/тёмная темы на semantic-токенах.
- `app.js` — навигация и лёгкие демонстрационные взаимодействия.
- `IMPLEMENTATION_PLAN.md` — план переноса победившего направления в production одним PR.
